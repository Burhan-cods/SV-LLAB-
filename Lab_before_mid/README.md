# Polar Vault Specification and Verification System (PSVS)

This folder contains Task 1 and Task 2 deliverables for the Polar Vault lab.

## Scenario
The Polar Vault stores sealed seed boxes deposited by registered institutions. Depositors retain ownership, while the vault acts as custodian.

## Task 1 — Orientation and Configuration Management
- `requirements/PSVS-REQ-v1.0.md`: baseline requirements S1–S12.
- `reports/change-request-template.md`: change-request template.
- Required Git workflow: baseline commit, tag `baseline-1`, three defect-analysis commits, and merge to `main`.

## Task 2 — Defect Taxonomy and Verification Logging
- `reports/defect-taxonomy.md`: eight core defect categories and examples.
- `defect-logs/defect-log.md`: candidate findings against S1–S12.
- `reports/defect-summary.md`: counts by category/severity and a text chart.
- `reports/peer-review-comparison.md`: template for actual classmate comparison and detection-rate calculation.

## Note
Peer-review results must be filled in after exchanging logs with a classmate. The defect entries are candidate review findings and should be validated during the lab.
